For integrators, maintainers and agent operators

Compatibility is a workflow property.

A valid signature is necessary, but it does not prove that a multi-step integration survives the real edges of a mailbox workflow. Rosetta observes the complete sequence and evaluates it with deterministic assertions — no model decides the verdict.
